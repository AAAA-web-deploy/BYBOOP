# BYBOOP — Cursor Website Kit

## What is included
This is a **working, lightweight static Astro website starter**, plus generated BYBOOP art, editable site configuration, download-ready stickers, and a comprehensive Cursor prompt. There is no need to recreate an image, copy code out of a chat, or add external assets.

## 3 steps
1. **Unzip this package** and open the `BYBOOP_Cursor_Package` folder in Cursor.
2. Open `CURSOR_BUILD_PROMPT.md` and paste its entire contents into Cursor Agent. Since the starter already exists, the agent should **improve and verify this code, not rebuild from scratch**.
3. In the integrated terminal, run `npm install` then `npm run dev`. When ready, run `npm run build` and deploy the `dist/` folder to a static host (Netlify, Cloudflare Pages, Vercel, etc.).

## Important launch configuration
Edit **`src/data/config.ts`** only with verified contract, tokenomics, X, Telegram, chart and swap URLs. NULL means intentionally unpublished. Do not invent contract addresses, exchange listings, LP/ownership claims, or social URLs. Until configured, the site displays honest prelaunch placeholders.

## Artwork
- `public/assets/hero-chaos.webp` — new hand-drawn hero art
- `public/assets/story/*.webp` — new image-heavy illustrated lore panels
- `public/assets/stickers/*.webp` — optimized transparent reaction sprites of the approved BYBOOP character
- `public/assets/downloads/*.png` — high-resolution PNG versions for site visitors
- `public/assets/og-byboop.jpg` — generated social card
- `public/favicon.svg` — locally created illustrated mark

No third-party fonts, icon libraries, animation libraries, trackers, crypto SDKs, or remote imagery are loaded by default.
